# Perguntas Frequentes

Plugin WordPress para gerenciar FAQs com categorias, busca e acordeão.

## Recursos

- CPT **FAQ** (pergunta + resposta)
- Taxonomia **Categorias**
- Shortcode `[perguntas_frequentes]` ou `[pf_faq]`
- Widget Elementor
- Busca e filtro por categoria no front
- Schema JSON-LD `FAQPage`
- Conteúdo inicial opcional via seed

## Shortcode

```
[perguntas_frequentes]
[perguntas_frequentes categoria="produtos" busca="1" categorias="1"]
```

## Requisitos

- WordPress 6.0+
- PHP 7.4+
